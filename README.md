# Python Runner

파이썬 파일을 실행 시키는 도커 이미지

## 구성 파일

- init.sh
- app.py
- requirements.txt

## 환경 변수

| Parameter        | Default | Function        |
|:-----------------|:-------:|:----------------|
| PYTHON_FILE_NAME |   app   | 실행 시킬 파이썬 파일 이름 |

## 이미지 이름

```bash
ghcr.io/e4-docker/python-runner:latest
```
